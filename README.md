### 帮助信息

```
./rtty -h

用法: /tmp/var/rtty [选项]
      -I, --id=字符串           为设备设置一个ID(最大63字节，有效字符：字母、数字、下划线和短横线)
      -h, --host=字符串         服务器的主机名或IP地址(默认为localhost)
      -p, --port=数字           服务器端口(默认为5912)
      -d, --description=字符串  为设备添加描述信息(最大126字节)
      -a                        自动重连服务器
      -i 数字                   设置心跳间隔时间(秒)(默认为30秒)
      -D                        后台运行
      -t, --token=字符串        认证令牌
      -f 用户名                 跳过第二次登录认证。有关详细信息，请参阅login(1)手册
      -R                        接收文件
      -S 文件                   发送文件
      -v, --verbose             显示详细信息
      -V, --version             显示版本信息
      --help                    显示此帮助信息
```
